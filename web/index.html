Parcours conseillé

  1. Socle : Excel avancé, SQL (jointures, agrégations, fonctions fenêtre), nettoyage des données.
  2. Restitution : Power BI, Power Query, DAX et conception de tableaux de bord utiles au métier.
  3. Analyse : statistiques descriptives, indicateurs, tendances, anomalies et interprétation claire.
  4. International : Python (pandas), anglais professionnel, portfolio avec 2 ou 3 projets documentés.
  5. Spécialisation : API/JSON + cloud pour les rôles data/BI modernes ; dbt et orchestration pour viser Data Engineer.

Conseil pratique : publie un projet de bout en bout (question métier → SQL → dashboard → recommandations) sur GitHub ou dans un portfolio.
